# limebowl — δημόσια σελίδα

Τι ετοιμάζεται, ψηφοφορία, και φόρμα για προβλήματα και ιδέες.
Ζωντανά: https://ismikari.github.io/nevora-roadmap/

Τα δεδομένα έρχονται από τον πίνακα `roadmap_items` του Supabase (δημόσια
ανάγνωση) και οι ψήφοι από τον `roadmap_votes`. Το κλειδί μέσα στη σελίδα είναι
το **publishable** — δημόσιο εκ σχεδιασμού· την προστασία την κάνει το Row Level
Security, όχι η μυστικότητα του κλειδιού.

**Τα στοιχεία δεν γράφονται από τη σελίδα.** Μπαίνουν με migration ή από το
dashboard: ανοιχτή εγγραφή σε δημόσια διεύθυνση σημαίνει spam μέσα σε μέρες.
Η φόρμα «Πες μας κάτι» γράφει στο `feedback`, που είναι **ιδιωτικό** — κανείς
δεν διαβάζει το μήνυμα κάποιου άλλου.

---

## ⛔ Η ΔΙΕΥΘΥΝΣΗ ΜΕΝΕΙ `nevora-roadmap`

Η εφαρμογή μετονομάστηκε σε **limebowl** στις 8/11/2026. Η **εμφάνιση** της
σελίδας ακολούθησε· η **διεύθυνση** όχι, και αυτό είναι απόφαση:

- Είναι γραμμένη στο `lib/app_info.dart` (`kRoadmapUrl`) κάθε έκδοσης που
  έχει ήδη εγκατασταθεί. Μετονομασία του repo σημαίνει **404** στο κουμπί
  «Τι έρχεται · ψήφισε» για κάθε tester που δεν θα ενημερωθεί.
- Το ίδιο ισχύει για το `localStorage` κλειδί `nevora_voter` μέσα στη σελίδα:
  αν αλλάξει, κάθε ψήφος που έχει ήδη δοθεί ξεχνιέται.

Αλλάζει **μόνο** όταν η σελίδα μεταφερθεί κάτω από το `limebowl.com` — και
τότε εδώ μένει ανακατεύθυνση, δεν σβήνεται τίποτα.
